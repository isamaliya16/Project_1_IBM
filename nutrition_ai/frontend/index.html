🤖 About This Application

NutriGuide AI is a web-based Agentic AI application built following all phases of the Agentic AI Software Development Life Cycle (SDLC). It uses IBM Granite LLM via IBM watsonx.ai to generate personalized nutrition plans and answer dietary queries.

🔄 Agentic AI SDLC Phases

  1. Problem Identification: Personalized nutrition guidance gap
  2. Agent Design: NutritionAgent with IBM Granite LLM
  3. Data Collection: Structured user profiling form
  4. Safety & Guardrails: GuardrailEngine (input validation, harmful content filter, output sanitization)
  5. Model Integration: IBM Granite 13B Instruct via watsonx.ai
  6. Development: Flask backend + HTML/CSS/JS frontend
  7. Testing & Validation: Fallback mock mode + error handling
  8. Deployment: Local server with .bat launcher
  9. Monitoring: Logging, ethics enforcement, disclaimers

🛡️ AI Ethics & Responsible AI

  • ✅ Transparency: Clear AI-generated content labeling
  • ✅ Harmlessness: Blocks dangerous dietary advice
  • ✅ Fairness: Inclusive of all dietary cultures
  • ✅ Privacy: No persistent user data storage
  • ✅ Accountability: Medical disclaimer on every plan
  • ✅ HAM Principle: Helpful, Accurate, Mindful responses

⚙️ Technology Stack

  • 🧠 AI Model: IBM Granite 13B Instruct
  • ☁️ Platform: IBM watsonx.ai
  • 🐍 Backend: Python 3.11 + Flask
  • 🌐 Frontend: HTML5 + CSS3 + Vanilla JS
  • 🛡️ Safety: Custom GuardrailEngine
  • 📄 Export: Markdown (.md) plan files

⚕️ Medical Disclaimer

This application provides AI-generated nutritional information for educational and informational purposes only. It is not a substitute for professional medical advice, diagnosis, or treatment. Always consult a qualified healthcare provider, registered dietitian, or licensed nutritionist before making significant dietary changes, especially if you have existing medical conditions.
